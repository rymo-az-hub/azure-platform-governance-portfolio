# ADR-005: AVD運用標準化の位置づけ

## Status

Accepted

## Context

AVD運用では、セッションホスト削除、ユーザー割当、棚卸し、接続不可時の切り分けなど、確認漏れが影響につながりやすい作業がある。

一方で、本リポジトリの主軸はAzure Governance / Policy Baselineである。AVDを前面に出しすぎると、Azure基盤全体の設計という主題が弱くなる。

## Decision

AVD運用標準化は、サブテーマとして扱う。

位置づけは、Azure Governanceの考え方を実運用へ適用した例とする。

対象は以下とする。

- HostPool棚卸し
- SessionHostライフサイクル
- Personal Desktop割当
- 接続不可時の切り分け
- 作業チェックリスト
- 顧客回答テンプレート

## Alternatives Considered

| 案 | 判断 |
|---|---|
| AVDをメインテーマにする | Azure基盤全体の設計としては狭く見えるため不採用 |
| AVDを完全に除外する | 実務運用改善の具体例が弱くなるため不採用 |
| サブテーマとして扱う | メイン設計と実運用改善を接続しやすい |

## Consequences

AVD運用標準化をサブテーマにすることで、実運用での標準化、自動化、証跡化を示しやすくなる。

ただし、AVD設計そのものを主題にしないため、AVDアーキテクチャの詳細設計は別範囲とする。
